Documentation

Commands

/obfuscate

/obfuscate file:script.lua

Obfuscates a Lua file.

/createloader

/createloader script:script.lua

Stores script and creates a remote loader.

/deleteloader

/deleteloader id:loader_id

Deletes a loader.

/listloaders

/listloaders

Lists all stored scripts.

API Endpoints

GET /api/stats

Returns total scripts, loaders, and loads.

GET /api/load?id=SCRIPT_ID

Loads a stored script.

GET /api/loader?id=LOADER_ID

Returns loader code.
