Features

String Encryption

Every string in your script is encrypted and only decrypted when needed at runtime.

Name Mangling

Variables and functions are renamed to random, meaningless identifiers.

Junk Code Injection

Fake code is inserted throughout your script to throw off reverse engineers.

Loader System

Store scripts on remote servers and load them on-demand with local caching.

REST API

Full API access for script management, stats, and control.

Lightning Fast

Obfuscation completes in milliseconds, even on large scripts.

Documentation

Obfuscate a Script

/obfuscate file:script.lua

Upload a Lua file and receive the obfuscated version instantly.

Create a Loader

/createloader script:script.lua

Store your script on the server and generate a remote loader.

Delete a Loader

/deleteloader id:loader_id

Revoke access to any loader instantly.

View All Scripts

/listloaders

See every stored script and its load count.
